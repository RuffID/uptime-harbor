# Рабочие циклы и локальная схема

`RestartableWorker` публикует результаты только из активного поколения. При остановке сначала закрывается `RuntimeWriteGate`, затем ожидаются завершение циклов и выход всех удержанных операций.

Локальные записи прежней установки сохраняются в модели EF для соответствия истории миграций. Они исключены из общей проекции и снимков.
