# Локальный setup и runtime

InstallationIntent=Setup обрабатывается до legacy initialization. Межпроцессный installation/storage lock удерживается весь срок процесса; порядок блокировок transition → runtime lifecycle → membership → write gate. Секреты и профиль не реплицируются. SQL-транзакции не охватывают файловые и сетевые операции.

AES-GCM использует отдельный persistent wrapping-key volume, без DPAPI. Не восстанавливать пароль из изменённого config, не активировать orphan key files. Любая неизвестная evidence оставляет common/peer/delivery gates закрытыми. Логи содержат только ID, фазу, revision/generation и закрытый reason code после durable результата.

Purpose issuer использует epoch в AES AAD. Startup загружает exact install/cluster/generation/node/storage issuer refs перед ReconcileAll; foreign/duplicate/orphan refs закрывают запуск. Новый BootChallenge создаётся InstallationLease на каждый процесс и не восстанавливается из профиля. Accepted process resume и ManagedRestart не заменять локальной lease. ManagedStorageSeals связывает AEAD checkpoint с profile/manifest/snapshot/SQL; restart запускает только целый прежний storage в quarantine до majority, затем требует новый ProcessEpoch/Enable. Отсутствующий/усечённый WAL и offline markers не разрешают catch-up fallback.

Protected invitation — inline AES envelope в локальной attempt; после доказанного accepted reserve удаляется до issue. JoinEnrollmentAuthority сохраняет прежние key/CSR/request/IDs/DER и reconciles lost response через fresh read-state. EnrollmentTrustInstallation сохраняет SQL intent перед protected manifest, не активирует orphan/partial refs. EnrollmentProbeSession выдаёт certificate/allowlist ≤2 минут только для фиксированной peer-пробы до runtime; ordinary peer/Raft/common gates не открывать. Public BotId первого берётся из ExpectedBotId либо bounded getMe, Join получает его из descriptor без token. DNS проверять на каждом connect с IP pinning/SNI, redirects/cookies/proxy запрещены.

Setup production Bootstrap проходит точные GenesisAuthorization/permit/account и отдельные accepted process/activation/enable; setup identity не становится common user. ManagedRestart пока связан с новым первым; полноценный Join/snapshot/membership — 05, sender — 05а. Не объявлять E4 общим Ready и не обходить закрытые production gates незавершённых сценариев 04.
