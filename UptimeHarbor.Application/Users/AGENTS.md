# Управление пользователями

`UserManagementService` координирует account store и сценарный Unit of Work видимости. `IUserAccountStore` скрывает Identity и его ошибки.

Запрещать отключение/удаление текущего и последнего включённого администратора. Права контейнера требуют права родительского сервера; контейнер без сервера нельзя назначить обычному пользователю; expected store errors преобразуются в прикладной результат.
