# Администрирование объектов

`ObjectAdministrationService` проверяет administrator policy и координирует изменения через `IObjectAdministrationUnitOfWork`. `IObjectAdministrationChangePublisher` сообщает Web об успешном сохранении.

Сохранять optimistic concurrency через `Version`, проверку уникальности имени и подтверждение количества отвязываемых контейнеров. Общий список включает контейнеры без сервера. Выбор связей сервера сохраняется вместе с настройками в одной транзакции; версии контейнеров обязательны, захватывать контейнер другого сервера через этот список нельзя. Контейнер может менять или снимать свой сервер; прежние permissions удаляются, версии обоих серверов увеличиваются. Удаление сервера отвязывает контейнеры, сохраняя их monitoring state и Telegram bindings. Disable/endpoint reset отменяет recovery прежнего incident в той же транзакции; publisher вызывается после сохранения.
