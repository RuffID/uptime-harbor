# Модели главной панели

Read records и `DashboardReadSnapshot` — независимый результат инфраструктурной проекции; dashboard DTO — результат для Web.

Не включать endpoint URL и EF entities. Сохранять UTC timestamps, раздельные имена сервера и принадлежность контейнера серверу; JSON-названия проверяются Web-контрактами.
