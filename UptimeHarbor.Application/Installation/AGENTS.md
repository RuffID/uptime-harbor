# Локальная установка

Контракты установки не содержат EF, HTTP и криптографические реализации. Профиль и шаги локальны, не являются ProjectionRecord и не входят в snapshot. Изменение фазы требует expected revision/generation, durable intent предшествует внешнему эффекту. Production authority этапа 04 закрыта; double не даёт рабочего допуска. Setup identity никогда не становится общим Administrator.
