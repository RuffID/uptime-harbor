# Модель получателя событий

`MonitoringRecipientReadRecord` передаёт идентификатор пользователя и признак администратора из Infrastructure в resolver.

Не передавать Identity entity и не загружать роль отдельным запросом на пользователя. Разрешённые user-id вычисляются вместе с пакетными permission-наборами.
