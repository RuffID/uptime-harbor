## Проверки

На отдельно разрешённом стенде проверить migrations/constraints, OperationId uniqueness, данные + курсор, конкурентные ACL и crash при apply.

Строки [общей матрицы](main.md#матрица-обязательных-сценариев) проверяются на всех указанных уровнях. Результаты этой категории не закрывают автоматически остальные категории.

Команды из плана не являются разрешением их запускать. Непроведённая обязательная проверка остаётся открытой; готовность кода при ожидающей приёмке обозначается `verification`.
