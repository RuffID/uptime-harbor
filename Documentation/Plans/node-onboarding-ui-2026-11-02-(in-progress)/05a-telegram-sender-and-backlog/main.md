# Шаг 2. Ручное переключение Telegram

Статус — `completed`. Реализация и изолированные проверки завершены 2026-11-22.

На странице **Telegram** администратор выбирает **«Назначить отправителем»** рядом с нужным NodeId. После принятия заявки кластер показывает выбранный узел. Выбор действует до следующего ручного переключения. [Управление отправителем](../../../Technical%20documentation/Notifications.md#назначение-отправителя-в-кластере).

При лидере №3 отправку передали с №1 на №2. Подставной Telegram получил одно сообщение. После возврата №1 и смены лидера отправителем остался №2. Назначение №3 без токена было отклонено, выбор сохранился. После ручного возврата следующее событие отправил №1. Назначенные проверки объектов продолжались.

Прошли 119 тестов .NET и 13 frontend-тестов. Проверка в браузере и доставка в реальный чат ожидают [приёмки пользователем на шаге 3](../07-verification-and-rollout/main.md).
