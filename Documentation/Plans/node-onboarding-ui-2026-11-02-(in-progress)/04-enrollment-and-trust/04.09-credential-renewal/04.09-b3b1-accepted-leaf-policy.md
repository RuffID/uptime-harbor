### B3b1 выполнена — 2026-11-18, NUI-04-20261118-08

`VoterCredentialPolicy.IsUsable` ограничивает доверие к старому credential на accepted peer registry и в dedicated live TLS. `DynamicPeerTls` сверяет ID, fingerprint и node/storage/address предъявленного leaf на одном срезе. Legacy registry теперь применяет ту же границу, а Direct и proxy сохраняют прежние CRL и chain/identity gates. `PeerServerPin.ResolvePresentedAsync` возвращает точный credential по SHA-256 и host/port при overlap и перепроверяет его по ID. Действующий исходящий RPC и B3a используют прежний режим одного credential до сквозного подключения в B3b2. $out = 'D:/Media/User/source/repos/uptime-harbor/artifacts/compile-check'
$names = 'UptimeHarbor.Application','UptimeHarbor.Infrastructure','UptimeHarbor.Web',
    'UptimeHarbor.Application.Tests','UptimeHarbor.Infrastructure.Tests','UptimeHarbor.Web.Tests'
foreach ($name in $names) {
    $project = if ($name.EndsWith('.Tests')) { "tests/$name/$name.csproj" } else { "$name/$name.csproj" }
    dotnet build $project -c Debug --no-restore "-p:BaseOutputPath=$out/b3b1-$name/" -p:TypeScriptCompileBlocked=true -p:BuildingInsideVisualStudio=false
    if ($LASTEXITCODE -ne 0) { throw "Compile-check failed for $name" }

$filters = @{

    dotnet test --project "tests/$name/$name.csproj" --no-build --no-restore "-p:BaseOutputPath=$out/b3b1-$name/" -p:TypeScriptCompileBlocked=true -p:BuildingInsideVisualStudio=false -- @mtpFilters --no-progress
    if ($LASTEXITCODE -ne 0) { throw "Tests failed for $suite" }
}
