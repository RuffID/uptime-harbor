## Границы и работы

- Согласовать текущие AGENTS/Onboarding contracts/Local installation setup/Cluster runtime/control/Configuration/Web/Testing с фактическими gates.
- Проверить размер новых C# файлов, разнести несколько record из EnrollmentPeerProbe.cs по принятому стилю при необходимости, сохранить контракты; исторические 01–03 не актуализировать вслед за кодом.

Затрагиваемые части: Application trust/admission, Infrastructure Installation/Cluster/Identity/crypto/HTTP, Web setup/enrollment, тесты и актуальная техническая документация.

## Проверки и критерии готовности

- Ссылки/solution/UTF-8/EOL согласованы; устаревшая фраза о полностью закрытом Bootstrap удалена только из актуальных описаний.
- Изолированный success/неприменённая migration/настоящие Ubuntu/SQL/TLS явно различаются.

Использовать только разрешённые статические, compile-check и изолированные проверки. Приложение, БД, Docker, сеть, браузер и Telegram этим файлом не разрешаются; внешнее подтверждение относится к этапу 07.
