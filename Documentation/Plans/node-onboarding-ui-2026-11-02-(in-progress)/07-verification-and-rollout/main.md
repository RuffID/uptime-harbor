# 07. Проверки и ввод

Прежний этап отложен. Статус на момент пересмотра — `not-started`.

**Объём MVP.** Пользователь подключает три узла по инструкции, останавливает №1, проверяет свежий результат от №2 и вручную переключает Telegram. После возврата №1 проверяет ручную передачу отправки обратно. Приёмка открыта.
