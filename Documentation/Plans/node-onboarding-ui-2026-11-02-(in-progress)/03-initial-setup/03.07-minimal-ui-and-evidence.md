## Границы и работы

- Подключить минимальные login/status/E0/logout с безопасными сообщениями, без полного Join-мастера.
- Зафиксировать durable setup/preflight/runtime события, исторические compile/изолированные результаты и внешние ограничения.

Затрагиваемые части: Web Setup и composition root, Infrastructure Installation/Identity/Cluster, локальные UoW и изолированные тесты.

- Неприменённая migration, SQL/ACL/fsync/TLS/browser и живое переключение явно отделены.
