# 03.04. Локальные секреты, locks и reconciliation

Статус: `completed`. Зависимости: [03.03](03.03-profile-attempt-and-cas.md)

Историческая декомпозиция завершённого объёма. Статус унаследован из результата этапа; отдельные новые проверки по этому файлу не выполнялись. Повторная реализация не поручена.

## Цель и результат

Защищённое локальное хранилище и восстановимые ссылки.

Основание: [обзор этапа](main.md), [общий план](../main.md), [согласованный контракт](../technical-design.md#runtime). При расхождении краткой задачи с полным объёмом этапа требования не ослаблять; противоречие зафиксировать до зависимой работы.

## Границы и работы

- Подготовить AES-GCM references/files, ограниченные пути, atomic publication, installation/storage locks и проверку SQL/file refs.
- Сохранять local volumes и существующую конфигурацию, не вводить DPAPI и не переносить ключи оператора.

Затрагиваемые части: Web Setup и composition root, Infrastructure Installation/Identity/Cluster, локальные UoW и изолированные тесты.

## Проверки и критерии готовности

- Corrupted refs/orphans и второй exclusive handle не обходят lock/проверки.
- Protected invitation удаляется после reserve, secret bodies не логируются.

Доказательства и пределы подтверждения — в [исходном результате этапа](main.md#результат). Сводные числа тестов этапа не означают отдельного прогона для этого файла.

## Фактический результат

Завершено в составе исходного этапа. Новая декомпозиция не добавляет заявлений о реализации или доказательств сверх его исторического результата.
