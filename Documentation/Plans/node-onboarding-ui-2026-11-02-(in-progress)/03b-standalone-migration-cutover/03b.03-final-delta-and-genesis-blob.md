# 03b.03. Финальная delta и sealed genesis blob

Статус: `not-started`. Зависимости: [03b.02](03b.02-freeze-and-drain.md)

Это план будущей работы. Реализация и проверки по этому файлу не выполнены; запись задачи не является разрешением на внешние действия.

## Цель и результат

Проверенный provisional state и исходный архив до native эффекта.

Основание: [обзор этапа](main.md), [общий план](../main.md), [согласованный контракт](../technical-design.md#migration). При расхождении краткой задачи с полным объёмом этапа требования не ослаблять; противоречие зафиксировать до зависимой работы.

## Границы и работы

- Применить final delta к shadow, сохранить source archive/manifest и sealed bounded-stream genesis blob с точным digest.
- Подготовить immutable GenesisImportState для quarantined replay; не создавать фиктивный JournalPosition(0) или accepted snapshot.

Затрагиваемые части: Application migration use cases, Infrastructure genesis/import/identity/history, Web lifecycle/status, тесты и актуальная техническая документация.

## Проверки и критерии готовности

- Изменённый cut, потерянный/corrupt blob, большой baseline и ограничение места держат M2 закрытым.
- Изолированные file/WAL сценарии не объявляют доказанными fsync/SQL atomicity.

Использовать только разрешённые статические, compile-check и изолированные проверки. Приложение, БД, Docker, сеть, браузер и Telegram этим файлом не разрешаются; внешнее подтверждение относится к этапу 07.

## Фактический результат

Не принят. При выполнении зафиксировать конкретный результат, применимые проверки и существенные непроверенные сценарии. Наличие кода или HTTP Pending само по себе не закрывает критерии.
