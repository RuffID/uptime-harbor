## Границы и работы

- Свести fake HTTP/DOM/time тесты отдельных задач, проверить недостающее покрытие клавиатуры/фокуса/modal/labels и cleanup обработчиков.
- Выполнить разрешённый tsc/изолированные frontend checks при соблюдении скиллов; актуализировать Web application/operations/местные AGENTS и solution навигацию.

Затрагиваемые части: Web Razor Pages/Shared, TypeScript pages/api/ui/state, HTTP/status DTO и изолированные frontend-тесты.

## Проверки и критерии готовности

- AJAX без reload/innerHTML, текущие Index/Users/Notifications/Disabled не регрессируют; generated output не правится вручную.
- Browser desktop/mobile/TLS остаются в 07; UI не пишет вторые backend success-логи.

Использовать только разрешённые статические, compile-check и изолированные проверки. Приложение, БД, Docker, сеть, браузер и Telegram этим файлом не разрешаются; внешнее подтверждение относится к этапу 07.
