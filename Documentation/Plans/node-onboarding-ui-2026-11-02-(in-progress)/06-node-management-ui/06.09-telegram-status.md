## Границы и работы

- Показать sender identity/связь/готовность локального token отдельно от leader; на несендерах «Токен не требуется».
- Показать Waiting/catch-up/план/доставлено N из M/ошибку части/ACK; при простое объяснить отсутствие автоматической замены.

Затрагиваемые части: Web Razor Pages/Shared, TypeScript pages/api/ui/state, HTTP/status DTO и изолированные frontend-тесты.

## Проверки и критерии готовности

- Follower sender не является ошибкой; Pending/Committed не означают доставлено.
- Нет копирования/вывода token, fake ACK кнопки и individual backlog replay; новый cut не скрывается старым итогом.

Использовать только разрешённые статические, compile-check и изолированные проверки. Приложение, БД, Docker, сеть, браузер и Telegram этим файлом не разрешаются; внешнее подтверждение относится к этапу 07.
