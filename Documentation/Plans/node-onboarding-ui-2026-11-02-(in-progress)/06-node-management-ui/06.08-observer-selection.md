# 06.08. Отдельный выбор объектов

Статус: `not-started`. Зависимости: [06.04](06.04-progress-and-reconnect.md), [06.05](06.05-errors-and-administrator-actions.md)

Это план будущей работы. Реализация и проверки по этому файлу не выполнены; запись задачи не является разрешением на внешние действия.

## Цель и результат

Отдельный понятный шаг назначений без смешения с синхронизацией.

Основание: [обзор этапа](main.md), [общий план](../main.md), [согласованный контракт](../01-scenarios-and-decisions/main.md#screens). При расхождении краткой задачи с полным объёмом этапа требования не ослаблять; противоречие зафиксировать до зависимой работы.

## Границы и работы

- После Joined предложить пустой по умолчанию список доступных объектов и actions сохранить/позже.
- Использовать отдельные observer commands/current versions; подтверждённые назначения отличать от Pending/частичного отказа и самого Join.

Затрагиваемые части: Web Razor Pages/Shared, TypeScript pages/api/ui/state, HTTP/status DTO и изолированные frontend-тесты.

## Проверки и критерии готовности

- Ноль выбранных, stale/deleted object, revoked admin и отсутствие majority.
- Нет назначения всех по умолчанию и изменения старых поколений/истории, пропуск шага сохраняет успешный Join.

Использовать только разрешённые статические, compile-check и изолированные проверки. Приложение, БД, Docker, сеть, браузер и Telegram этим файлом не разрешаются; внешнее подтверждение относится к этапу 07.

## Фактический результат

Не принят. При выполнении зафиксировать конкретный результат, применимые проверки и существенные непроверенные сценарии. Наличие кода или HTTP Pending само по себе не закрывает критерии.
