## Границы и работы

- Привязать issuance/reserve/consume/revoke/pause/continue события к durable apply, actor получать из принятой авторизации.
- Зафиксировать изолированные проверки pipeline/WAL/API, compile-check, непроведённую provider/сетевую приёмку и неприменённую migration.

Затрагиваемые части: Domain/Application Cluster, Infrastructure reducer/codec/snapshot/persistence, Web API и изолированные тесты.

## Проверки и критерии готовности

- Нет повторного success на известный replay и секретов в exception paths.
- Boundary TTL, lost response/leader change и строгие архивы соответствуют исходному результату этапа.

Доказательства и пределы подтверждения — в [исходном результате этапа](main.md#результат). Сводные числа тестов этапа не означают отдельного прогона для этого файла.
