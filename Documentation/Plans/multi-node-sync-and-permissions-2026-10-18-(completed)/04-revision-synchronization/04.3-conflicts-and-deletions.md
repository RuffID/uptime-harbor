## Проверки

Проверить update/update без отката принятого Б при позднем В, update/delete, конфликт одинаковых login, отключение актёра, уникальность chat ID, удаление родителя и старый update после tombstone; защищённые поля аккаунтов не выводятся.

Общие сценарии [родительского этапа](main.md#проверки) сохраняются. Изолированные проверки подтверждают алгоритм; реальные БД, peer HTTP, процессы, браузер и Telegram учитываются отдельно в [этапе 10](../10-verification-and-acceptance/main.md).

Команды из плана не являются разрешением их запускать. Непроведённая обязательная проверка остаётся открытой; готовность кода при ожидающей приёмке обозначается `verification`.

Отметки относятся к серверной границе и согласованным изолированным проверкам. Общий sign-in/UI, реальные SQL Server, сеть и внешняя приёмка не включены.

- [x] Нет silent overwrite, автоматического отката принятой правки и воскрешения; разрешение конфликта является новой авторизованной командой.
- [x] Работы и применимые проверки подэтапа выполнены, результат и ограничения зафиксированы.

## Результат выполнения

2026-10-29. Reducer сохраняет base/accepted/proposed и реальные base/current revisions; первая принятая версия действует до новой авторизованной команды с актуальной базой. Порядок решения задаёт Raft, включая обратный ход часов при разрешении конфликта. Tombstones блокируют старые updates; server delete отвязывает контейнеры, удаляет зависимые назначения/привязки; Pending на удалённые зависимости получает Cancelled. Проверены update/update, update/delete, одинаковые login/server name/chat ID, disable актора, deleted login reservation и поколение endpoint. Отдельно разрешённая migration `20261029075201_AllowUniquenessConflictRevisions` допускает competing revision старше base другой сущности; к БД не применялась.

Общий итог: отдельные production builds — 0 предупреждений/ошибок; Domain 36, Application 166, выбранные Infrastructure 65, Web Cluster/DI 22 успешно, без ошибок/пропусков. БД/SQL/provider tests, приложение/host, реальные peer/Telegram, Docker, deployment и Git не запускались. Migration не применялась. Crash/fsync, живой failover и часовая цель догона не доказаны; внешняя приёмка учитывается отдельно. Работа остановлена после 04 и 05.1.
