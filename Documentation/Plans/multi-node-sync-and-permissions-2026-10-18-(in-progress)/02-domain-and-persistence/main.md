# Этап 02. Доменная модель и долговременное хранение

Статус: completed

## Цель

Подготовить инварианты и схему отдельных БД узлов для общих пользователей, единственной роли, ревизий, заявок, инцидентов и доставки.

## Зависимости и границы

После [01](../01-protocol-and-contracts/main.md). Схема и миграции создаются в рамках отдельно разрешённой реализации; применение миграций к БД не входит в автоматическую проверку. Исторические baseline migrations не переписываются.

## Затрагиваемые части проекта

`UptimeHarbor.Domain/Monitoring`, `Domain/Access`, `Domain/Notifications`; `Application/Abstractions/Persistence`, `Application/Abstractions/UnitOfWork`; `Infrastructure/Persistence`, его `Configurations`, `UnitOfWork`, `Repositories`, новые миграции. Соответствующие Domain/Application/Infrastructure tests, ближайшие `AGENTS.md`; актуальные документы `Domain model.md`, `Persistence.md`, `Database migrations.md`.

## Границы ответственности подэтапов

02 отвечает за модель, storage-контракты и миграции схемы. Consensus adapter — 03; применение принятого журнала — 04; первый запуск и будущее восстановление — 09. Перенос прежних установок не входит в объём.

## Проверки

Изолированно: общие UserId, уникальность имени, защита последнего администратора, версии, EF metadata/индексы/связи без соединения. Провайдерные проверки с БД отдельно разрешаются и не заменяются fake-тестами.

Отдельная внешняя приёмка: создание чистой тестовой SQL Server БД со схемой новой модели, constraints и backup/restore. Compile-check не доказывает успешность применения схемы.

## Критерии приёмки

- [x] Модель задаёт общий UserId и канонический login; уникальность закреплена EF-индексом. Упорядоченное принятие команд подключается в 04/05.
- [x] ConfigRevision отделена от локального Version и результатов проверок; её присваивание выделено в отдельный метод принятой конфигурации.
- [x] Целевая модель содержит только Administrator без ACL, владельцев и домашнего узла; прежние типы разрешений оставлены для компиляции до 05.
- [x] Аккаунт, роль, версия и cursor входят в один projection UoW; чистый guard защищает self/last-admin. Конкурентное принятие общих команд относится к 04/05.
- [x] Receipt/digest и terminal decision/control ledger защищают повторное применение storage-пакета; внешние side effects не запускаются.
- [x] Новая migration и snapshot подготовлены без backfill; применение к БД и provider-зависимые проверки не заявлены выполненными.
- [x] Схема хранит общие аккаунты/роль, результаты отдельных observers и назначения чатов по NodeId.

## Связанные вопросы


Открытых вопросов нет. Условия HTTPS-связи, рабочий масштаб и порядок самостоятельной проверки закреплены в [техническом проектировании](../technical-design.md#11-среда-масштаб-и-порядок-проверки).

Согласованное поведение закреплено в [требованиях](../business-requirements.md); клиентских блокирующих вопросов нет.

Детали интеграции DotNext закрепляются этапом 01. Первый bootstrap, пустой join и будущий rejoin проверяются в этапе 09; сопоставление старых данных не требуется.

## Результат выполнения

Выполнено 2026-10-29: независимые модели и инварианты, долговременная SQL-проекция и локальные записи, EF mappings, узкие UoW и migration `20261029053354_AddSharedClusterStorage` с designer/snapshot. Подробности — [фактическая модель хранения](../../../Technical%20documentation/Shared%20cluster%20storage.md).

Минимальные изолированные проверки: Domain — 36, Application — 111, выбранные Infrastructure metadata/fake/DI — 27; ошибок и пропусков нет. Production-проекты собраны отдельно без Web-host. Команды и граница доказательств — [Testing.md](../../../Technical%20documentation/Testing.md#проверка-этапа-02).

Не выполнялись: применение Up/Down, provider tests (включая SQLite), SQL Server atomicity/crash/backup/restore, реальные узлы/HTTP/Telegram и deployment. Эти внешние категории не блокируют разработку согласно согласованному минимуму этапа 10. Consensus adapter, reducer/replay, общий вход и распределённые workers не реализованы; этапы 03–10 не начаты. Завершённые документы 01 сохранены без изменений.
