# UptimeHarbor.Domain

## Ответственность

Проект содержит доменные сущности, значения, статусы и локальные инварианты. Он не зависит от других проектов решения, EF Core, ASP.NET Core или интеграционных библиотек.

`Cluster` содержит общие идентификаторы, аккаунты, принятые записи и локальные durable-маркеры. `Access` оставлен для совместимости прежних вызовов; ресурсные права в целевую модель не входят.

## Правила

- Правило, проверяемое по состоянию одной сущности или агрегата без I/O, защищать внутри доменной модели.
- Не открывать сеттеры и изменяемые коллекции ради EF Core или тестов.
- Не добавлять DTO, HTTP-контракты, репозитории, Identity-типы и конфигурацию.
- Сохранять допустимое состояние через конструкторы и предметные методы.
- Контейнер может существовать без сервера; изменение связи проходит через доменный метод и сохраняет monitoring state.
- `MonitoredServer.Name` — обязательное административное имя; внутреннее имя из endpoint хранится отдельно в `LastKnownName`.
- При изменении сущностей или инвариантов обновлять этот файл, `Documentation/Technical documentation/Domain model.md` и относящиеся активные планы; завершённые планы не редактировать.
