# Административные TypeScript-модули

`objects.ts`, `users.ts` и `notifications.ts` обслуживают свои Razor Pages через MVC API, modal-формы и динамический DOM.

Использовать общий HTTP-модуль и DOM API без строкового `innerHTML`. Не перезагружать страницу ради изменений; сохранять antiforgery, отображение field errors и защиту от повторной инициализации.

Коллекции объектов, пользователей, permissions и Telegram-привязок отображаются через `shared/dataTable.ts`. Фильтры располагаются слева над таблицей, создание — справа; действия строк используют компактные текстовые кнопки. Фильтрация списка пользователей не должна сбрасывать несохранённые permissions. При снятии saving сохранять исходные ограничения disabled для полей доступа.

`users.ts` открывает редактор выбранного пользователя в Bootstrap modal, обновляет размеры таблицы permissions после `shown.bs.modal` и возвращает фокус в список после закрытия. Пока идёт сохранение, закрытие редактора блокируется; при ошибке окно остаётся открытым, при успешном сохранении/удалении закрывается после обновления списка.

При сохранении пользователя запрос `/enabled` отправляется только при отличии переключателя от `isEnabled` выбранной записи. Сохранение permissions с неизменённым состоянием учётной записи не должно вызывать этот endpoint, в том числе для текущего администратора.

`objects.ts` открывает редактор сервера вместе с контейнерами в одной scrollable modal и пересчитывает таблицу после `shown.bs.modal`. Окна редактора и создания контейнера переключаются через `hidden.bs.modal`, без одновременных backdrop/focus trap. Общие ошибки редактора показывать внутри окна, после закрытия возвращать фокус в список.

Для чата без привязок в таблице Telegram оставлять ячейки типа/объекта/действий привязки пустыми, без прочерков.
