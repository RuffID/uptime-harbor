# Общие frontend-компоненты

`http.ts` отправляет JSON, добавляет antiforgery token изменяющим запросам, передаёт `AbortSignal`, разбирает error envelope и раскрывает `ServiceResult`.

Сохранять `ApiError.field` и `status`, различать пустой/некорректный ответ и штатную отмену. Здесь нет UI-рендера; запросы страниц не должны создавать конкурирующий формат обработки ошибок.

`dataTable.ts` строит Bootstrap-таблицы с закреплённой шапкой и ограниченным высотой окна scroll-контейнером. Заголовки и ячейки используют одинаковые стабильные `data-column-key`; таблица сохраняется при обновлении строк. Фильтрация и запросы остаются в модулях страниц.

`tableColumnResizing.ts` и `helpTooltip.ts` перенесены из AquaByteLedger.Web и адаптированы: ширина хранится в localStorage под собственным префиксом, resize доступен мышью и стрелками клавиатуры, подсказки используют тёмную Bootstrap-тему и закрываются по Escape. Не заменять sticky-позиционирование заголовков относительным.

Таблица всегда занимает 100% ширины контейнера. Ширины колонок применять в процентах; сохранённые пиксельные значения использовать как пропорции. Перед resize фиксировать фактические ширины без изменения геометрии; дельту указателя перераспределять между выбранной и следующей колонками с ограничением их минимальных ширин. Внешнюю правую границу не делать перетаскиваемой. При отмене восстанавливать обе колонки, при завершении сохранять все ширины. Новые строки и изменение viewport сохраняют пропорции.

`searchableMultiSelect.ts` и `searchableRadioSelect.ts` перенесены из AquaByte-Ledger и адаптированы к тёмной теме. Исходный select хранит значения, controller.refresh() синхронизирует options/disabled и созданные checkbox/radio. Пустой список отключает кнопку и показывает «Нет объектов.» (для чатов — «Нет чатов.»). Radio поддерживает пустое значение для снятия связи/сброса фильтра; при закрытии modal закрывать панели.

Radio-панель внутри Bootstrap modal размещается непосредственно в корне modal с fixed-позиционированием: scroll-область и footer не должны её обрезать, фокус остаётся внутри окна. Выбирать сторону раскрытия по месту в viewport; закрывать при скрытии modal, внешнем scroll и resize. `panelMinWidth` расширяет только панель, сохраняя ширину кнопки фильтра.

`switchAnimations.ts` делегирует события переключателей с `data-animated-switch`. Анимация положения и цветов длится 300 мс через Web Animations API, повторное переключение продолжает текущее движение; при reduced motion анимация отключена. Не добавлять CSS ради этой анимации.
