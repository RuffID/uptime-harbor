# SignalR-уведомления UI

`MonitoringHub` предоставляет аутентифицированный канал. Monitoring event handler определяет разрешённых получателей через Application; административный publisher отправляет сигнал после сохранения.

Передавать только обезличенный сигнал, тип/ID объекта. Клиент перечитывает защищённый snapshot; SignalR не является хранилищем. Ошибка best-effort administrative publisher не отменяет уже успешное сохранение.
