# Razor Pages

## Ответственность

Каталог содержит пользовательские Razor Pages и регистрацию Web-presentation сервисов.

## Правила

- PageModel координирует HTTP/UI-поток, но не содержит persistence- и доменную логику.
- Для HTTP API использовать контроллеры, а не handlers страниц или Minimal API.
- Не передавать EF-сущности напрямую в представление; использовать UI-модели и DTO.
- Изменяющие формы защищать antiforgery и серверной авторизацией.
- При изменении жизненного цикла страниц или регистрации presentation обновлять этот файл и `Documentation/Technical documentation/Web application.md`.
- Страницы входа и выхода координируют только cookie-сценарий через инфраструктурную абстракцию и не обращаются к Identity stores напрямую.
- Страница входа использует отдельную login rate-limit policy; видимая ошибка не различает неизвестный логин, неверный пароль, disabled и временный Identity lockout.
- Административная страница объектов содержит только статические формы и контейнеры; создание и редактирование выполняются в Bootstrap modal, форма сервера включает обязательное имя, а коллекции загружает TypeScript через MVC API.
- Главная страница содержит только статические контейнеры панели; TypeScript раздельно показывает заданное и полученное внутреннее имя сервера, а поиск, snapshot, состояния UI и SignalR lifecycle координирует без перезагрузки.
- Главная страница подключает локальный SignalR browser asset версии 10.0.11 с `asp-append-version="true"`; внешний CDN не используется.
- Пачка monitoring/admin refresh-сигналов coalesce-ится 200 мс; новый snapshot отменяет прежний незавершённый fetch, а штатный `AbortError` не показывается как ошибка.
- Административная страница уведомлений содержит статические формы/контейнеры; создание/редактирование чатов и создание bindings выполняются в Bootstrap modal, а таблица показывает отдельную строку на привязку с именем и ID чата. Чат без привязок также остаётся видимым. TypeScript работает через MVC API без token в UI payload.
- Административная страница пользователей содержит только статические формы/контейнеры; создание и редактирование пользователя выполняются в отдельных Bootstrap modal, а пользователей и permissions загружает TypeScript через MVC API без `innerHTML`, с обязательной связью `id`/`name`/`label`.
- Главная и административные страницы используют общие таблицы с внутренним скроллом, закреплённой шапкой, изменяемой шириной колонок и helpTooltip. Фильтры находятся слева над таблицами, создание — справа; объекты и пользователи редактируются в модальных окнах.
