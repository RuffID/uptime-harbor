# Административные Razor Pages

Objects, Containers, Users и Notifications задают статические формы, Bootstrap modal и контейнеры для TypeScript-модулей.

В enabled-режиме страницы выбирают _ClusterAdministration с начальным разделом и _ClusterScripts. Общий Bootstrap modal обслуживает typed editor accepted/Pending/conflict; legacy модуль одновременно не подключать. Без browser readiness gates этот UI недоступен; наличие собранных форм не открывает controlled enable.

Коллекции загружаются через административное API; не дублировать загрузку в PageModel. Objects показывает «Сервера», Containers — отдельную страницу «Контейнеры». В редакторе сервера находится multiSelect свободных и текущих контейнеров; таблица, создание и редактор контейнеров принадлежат Containers. У контейнера необязательный сервер выбирается radioSelect с вариантом «Без сервера». Сохранять доступ только администратора.

На Users кнопка «Изменить» открывает отдельную modal состояния аккаунта. Единственная роль — Administrator; таблицы permissions и выбора владельца/узла нет. Сохранение выполняется через перехваченный submit; ошибки показываются внутри окна. Редактор под списком пользователей не добавлять.

Основные списки занимают ширину рабочей области и содержат контейнеры для общих TypeScript-таблиц. Панель поиска/фильтров находится непосредственно над списком слева, кнопки создания — справа. Сложные действия и заголовки сопровождаются helpTooltip; разметка не содержит серверного рендера строк.

Для переключателей использовать `role="switch" data-animated-switch`: плавность обеспечивает общий TypeScript-модуль без новых CSS. Поля поиска имеют явный `size` и Bootstrap `w-auto mw-100`, чтобы подсказка помещалась по ширине.
