# Административные Razor Pages

Objects, Users и Notifications задают статические формы, Bootstrap modal и контейнеры для TypeScript-модулей.

Коллекции загружаются через административное API; не дублировать загрузку в PageModel. Редактор сервера, список его контейнеров и редактор контейнера находятся в одной scrollable modal; создание контейнера временно закрывает редактор и возвращает в него после закрытия окна создания. Сохранять доступ только администратора.

На Users кнопка «Изменить» открывает отдельную modal с формой состояния учётной записи и таблицей permissions. Сохранение выполняется через перехваченный submit; ошибки показываются внутри окна. Редактор под списком пользователей не добавлять.

Основные списки занимают ширину рабочей области и содержат контейнеры для общих TypeScript-таблиц. Панель поиска/фильтров находится непосредственно над списком слева, кнопки создания — справа. Сложные действия и заголовки сопровождаются helpTooltip; разметка не содержит серверного рендера строк.

Для переключателей использовать `role="switch" data-animated-switch`: плавность обеспечивает общий TypeScript-модуль без новых CSS. Поля поиска имеют явный `size` и Bootstrap `w-auto mw-100`, чтобы подсказка помещалась по ширине.
