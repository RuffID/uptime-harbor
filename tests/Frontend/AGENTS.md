# Изолированные frontend-тесты

monitoringSnapshot.test.mts проверяет общий список серверов, связанных и самостоятельных приложений и совместное применение фильтров типа/статуса. Кластерный editor дополнительно проверяет выбор типа нового объекта и необязательную/позднюю связь приложения; существующий тип не меняется.

Compiled lifecycle API проверяется тем же fake fetch: antiforgery, точный payload control и 202 как очередь. Служебные команды не обходят shared HTTP и не означают разрешения запускать окружение.

clusterAdministration.test.mts проверяет production TS редактор/черновик/refresh с DOM-заглушкой: потеря ответа, стабильный OperationId, повторный конфликт/rebase, held confirmation, пароль только в памяти, stale responses и reconnect reads. API-проверка использует outputs штатной Web-сборки и fake fetch, включая antiforgery/202/403; перед ней нужен разрешённый Web compile-check. Bootstrap, геометрия/mobile и браузер отдельно не проверяются.

Проверять поведение общих TypeScript-компонентов через управляемые DOM-заглушки и геометрию. Запускать через `node --experimental-strip-types --test tests/Frontend/*.test.mts`, без приложения, браузера, сети и БД. `searchableSelects.test.mts` проверяет пустые/disabled списки, сохранение checkbox/radio-состояния и снятие связи. Такие проверки не заменяют визуальную проверку в браузере.

Radio-тест дополнительно проверяет размещение панели вне scroll-области modal, раскрытие вверх при нехватке места, выбор значения, закрытие при resize/скрытии modal и независимую ширину панели фильтра.

`tableColumnResizing.test.mts` проверяет постоянную ширину таблицы при перераспределении соседних колонок мышью и клавиатурой, минимальные ширины обеих колонок, отмену, сохранённые пропорции, новые строки и узкое окно. Геометрия задаётся DOM-заглушкой; браузерная проверка остаётся отдельной.
# Локальный setup

setup.test.mts использует fake DOM/FormData/fetch без browser/host/сети. Его shared/http.js берётся из artifacts/installation-setup/typescript после разрешённого локального tsc; production dist вручную не редактировать. Проверять CSRF refresh, очистку пароля, busy gate и отсутствие автоматического повтора mutation.
