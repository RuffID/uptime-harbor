# Изолированные frontend-тесты

Проверять поведение общих TypeScript-компонентов через управляемые DOM-заглушки и геометрию. Запускать через `node --experimental-strip-types --test tests/Frontend/*.test.mts`, без приложения, браузера, сети и БД. Такие проверки не заменяют визуальную проверку в браузере.
