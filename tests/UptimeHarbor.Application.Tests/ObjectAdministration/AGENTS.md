# Тесты администрирования объектов

Проверяются валидация, unique name, `Version`, удаление и публикация после сохранения на fake UoW.

Контейнер можно создать без сервера, привязать и отвязать с обеих сторон; удаление сервера сохраняет контейнеры. Проверять конфликт версии и попытку захвата контейнера другого сервера при multiSelect; ACL cleanup больше не вызывается.

Проверять отказ в доступе до I/O и атомарный запрос отмены recovery при reset. Fake transaction не является доказательством SQL Server locking.
