# Модель сетки

Проверять чистые инварианты аккаунтов, позиций, Pending/terminal decisions, наблюдений и delivery ledger через публичный API. Фиксированные UTC-времена, UUID и входные позиции заменяют реальный consensus. Последовательная симуляция принятых команд не доказывает конкурентную атомарность SQL Server.
