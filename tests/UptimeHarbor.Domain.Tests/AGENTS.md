# Тесты Domain

Наборы `Monitoring`, `Notifications` и `Cluster` проверяют публичные переходы сущностей и локальные инварианты без инфраструктуры. `Cluster` покрывает нормализацию аккаунта, отдельные ревизии, terminal операции, cursor, retention и delivery ledger.

Не ослаблять публичный API сущностей ради подготовки тестов. Использовать фиксированное UTC-время и отдельные сценарии граничных состояний.
