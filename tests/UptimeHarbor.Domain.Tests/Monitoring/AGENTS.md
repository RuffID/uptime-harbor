# Тесты доменного мониторинга

Проверяются конструкторы server/container, имена, статусы, ошибки, reset и успешные endpoint-результаты.
Оба типа используют MonitoredServer; проверять неизменяемый Type, запрет родителя у Server и сохранение monitoring state при поздней связи Application.

Переходы вызывать через публичные методы; не заменять доменную проверку тестом worker или HTTP. Время и три последовательные ошибки задавать явно.
